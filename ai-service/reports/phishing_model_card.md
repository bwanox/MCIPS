# MCIPS Pilot Threat Classifier Model Card

## Model

- **Name:** `rules_tfidf_hybrid_v1`
- **Version:** `1.0.0-pilot`
- **Live use:** FastAPI inference combines deterministic security rules with a TF-IDF + logistic-regression phishing probability.
- **LLM role:** LLMs are not used for primary classification. They are reserved for incident reasoning and copilot assistance.

## Training And Evaluation Data

- **Corpus:** `ai-service/reports/data.csv`
- **Size:** 34 curated pilot messages
- **Labels:** 17 safe, 17 phishing
- **Languages:** English 12, French 8, Arabic 8, Darija 6
- **Status:** pilot benchmark only; not representative production telemetry

## Evaluation Method

The report in `ai-service/reports/evaluation_report.md` is generated by `python scripts/evaluate_models.py`.

- Five-fold stratified out-of-fold predictions
- Rules-only, TF-IDF-only, and hybrid comparison
- Confusion matrices, accuracy, precision, recall, F1, PR-AUC, ROC-AUC
- Median and p95 latency
- Final artifact trained on all 34 pilot examples after evaluation

## Runtime Output

The inference API returns:

- `model_used`
- `model_version`
- `decision_source`
- `component_scores.rules_score`
- `component_scores.ml_probability`
- `evaluation_status`
- `fallback_used`

## Intended Use

Use this model as a competition/demo baseline for privacy-preserving phishing triage in MCIPS. It is appropriate for explaining the pipeline and prioritizing alerts with human review.

## Limitations

- The dataset is too small for production accuracy claims.
- Language-specific metrics are unstable because each language has only a few samples.
- Attackers can adapt wording, encoding, and context.
- The model should not be the sole control for blocking accounts, messages, or network traffic.
